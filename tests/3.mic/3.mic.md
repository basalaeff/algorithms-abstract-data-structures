# MIC tests

```bash
./mic --q '{{1, 2, 3}, {2, 3, 4}, {5, 6}, {3, 4, 5}}'
# Result: {{2, 3, 4}, {3, 4, 5}}, common elements count: 2
```
```bash
./mic --q '{{1, 2}, {3, 4}}'
# Result: {{1, 2}, {3, 4}}, common elements count: 0
```
```bash
./mic --q '{{1, 2, 3}, {1, 2}, {2, 3}}'
# Result: {{1, 2, 3}, {2, 3}}, common elements count: 2
```
```bash
./mic --q '{{1, 1, 2, 2}, {2, 2, 3, 3}}'
# Result: {{1, 2}, {2, 3}}, common elements count: 1
```
```bash
./mic --q '{{10, 20, 30}, {30, 20, 10}, {1}}'
# Result: {{10, 20, 30}, {30, 20, 10}}, common elements count: 3
```
```bash
./mic --q '{{5}, {5}, {5}}'
# Result: {{5}, {5}}, common elements count: 1
```
```bash
./mic --q '{{1}, {2}, {1, 2}}'
# Result: {{1}, {1, 2}}, common elements count: 1
```
```bash
./mic --q '{{100, 200, 300}, {200, 300, 400}, {100, 200, 300, 400}}'
# Result: {{200, 300, 400}, {100, 200, 300, 400}}, common elements count: 3
```
```bash

```
```bash
./mic --q '{{7, 8, 9}, {1, 7}, {7, 8}}'

```

## Error tests

```bash
./mic --q '{{1, 2, 3}}'
# Error: At least two sets are required.
```
```bash
./mic --q '{{1, 2}, {0}}'
# Error: Natural number must be greater than zero.
```
```bash
./mic --q '{{1, 2}, {-3}}'
# Error: Expected natural number.
```
```bash
./mic --q '{{1, 2}, {3, }}'
# Error: Expected natural number.
```
```bash
./mic --q '{1, 2}, {3, 4}'
# Error: Unexpected symbol outside outer set.
```
